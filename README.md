# Matemática Discreta I - Clase Práctica 4 (Lógica Proposicional)

Este repositorio contiene la presentación interactiva y los simuladores de lógica proposicional para la **Clase Práctica 4** de Matemática Discreta I de la Universidad Central de Venezuela (UCV). Está enfocado enteramente en la resolución práctica de ejercicios e inferencias, no en teoría pura.

## 🚀 Características
- **Framework de Presentación Web:** Construido en Vanilla HTML/CSS/JS, sin dependencias externas pesadas.
- **Simulador Lógico en Vivo:** Un motor interactivo (Sandbox) que evalúa en tiempo real variables lógicas ($p, q, r...$) y determina contramodelos (Pruebas de Invalidez).
- **Diseño Premium UI/UX:** Interfaz *Dark Mode* de alto contraste optimizada para entornos educativos, con soporte responsive y animaciones de Focus Syntax.

## 📂 Estructura del Repositorio
- \`index.html\`: Archivo principal de la presentación.
- \`assets/css/\`: Hojas de estilo y componentes visuales.
- \`assets/js/renderSlides.js\`: Motor de renderizado que inyecta y controla las diapositivas.
- \`assets/js/slides/\`: Directorio que contiene cada lámina modularizada (ej. \`validity.js\`, \`methods-review.js\`).
- \`assets/logos/\`: Recursos gráficos y multimedia.
- \`docs/\`: Documentación adicional y PDFs de apoyo.

## 🛠️ Cómo Usarlo
No requiere instalación de paquetes ni compilación. Simplemente abre el archivo \`index.html\` en cualquier navegador moderno o sirve la carpeta utilizando un servidor local (ej. Live Server en VS Code).
